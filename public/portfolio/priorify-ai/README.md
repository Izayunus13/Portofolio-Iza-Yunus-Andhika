# Priorify AI walkthrough

Source: https://priorify-ai-nu.vercel.app/

Twelve original browser screenshots, ordered from the public landing page through the built-in demo: dashboard, task entry, task ranking, availability, generated schedule, assistant guidance, task breakdown, completion, settings, Midnight theme, and mobile dashboard.

Captured with Edge at 1440 x 1000 (desktop) and 390 x 1000 (mobile), with WebP output. The task table and generated schedule use focused element screenshots. Capture notes preserve the visible text for each final image.

The prototype task and Thursday study slot are illustrative entries in an isolated demo browser session. The assistant responses are the actual outputs of the site's simulation, as disclosed in its settings. No personal account or credentials were used.

Portfolio content is in `lib/portfolio.ts`, under `programming-c` (Portfolio C, Bytehaven).
