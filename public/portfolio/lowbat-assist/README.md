# LOWBAT Assist captures

Source: https://lowbat-assist.vercel.app/

Thirteen original browser screenshots document the dashboard, working guide, responsibility directory, expanded faculty assignments, generator entry, template choice, delegation form, opponent picker, match form, crosscheck preview, filtered shared history, saved message detail, and mobile dashboard. Gallery order follows that journey; filenames retain capture order.

Desktop pages use a 1600px viewport at 1.5x pixel density. Tall form captures include all match fields. Focused dialogs are captured directly from their elements. Mobile uses a 390 x 844 viewport. Images open at original resolution from the portfolio gallery.

Sample form values are demonstration inputs. The walkthrough stops at crosscheck and does not generate or save records. History images show existing records. Capture automation blocks remote API mutations. Captions describe observed features; no account roles, automatic message delivery, or additional active templates are assumed.
